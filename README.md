# Пиксельные привычки

Трекер привычек, в котором выполнение привычек раскрашивает пиксельную картину, а пропуски запускают заражение. Правила игры и модель MVP описаны в документе «Трекер привычек: правила игры и модель MVP».

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # тесты игрового движка
npm run build
```

## Что внутри

- `src/engine/` — игровой движок без зависимостей. Состояние картины считается чистой функцией `simulate()` от журнала отметок, поэтому дозаполнение и отмена отметок честно пересчитываются.
  - `simulate.ts` — раскраска, заражение, очаги, щиты, паузы, окно дозаполнения, клетки «под угрозой».
  - `picture.ts` — конвейер «картинка → сетка»: k-средних в CIELAB, чистка шума, фон, привязка цветов к привычкам, порядок открытия, скорость раскраски P.
  - `presets.ts` — уровни сложности «Мягкий», «Обычный», «Жёсткий».
- `src/components/` — экраны: мастер первого запуска, «Сегодня», привычки, статистика, коллекция.
- `src/lib/store.ts` — хранение прогресса. В этой версии всё хранится в браузере (localStorage), без сервера и регистрации.
- `public/library/` — пять собственных картинок для старта.

## Тест-режим

Внизу страницы есть кнопка «+1 день»: она сдвигает дату, чтобы проверить заражение и восстановление без ожидания реальных дней.
